I published my first nuget package [Bangla.net](https://www.nuget.org/packages/Bangla.net/#readme-body-tab).
Its a library that converts Georgian calendar to Bangla calendar and Roman 
Numerics to Bangla numerics.

```csharp

var banglaWord = Number.ToBanglaWord("10011111002548976");

var banglaNum = Number.ToBanglaNumber(10011111002548976);
// output : ১০০১১১১১০০২৫৪৮৯৭৬
```

I recently added a feature on a python library, that does calendar data conversion 
from Georgian System to Bangla (Bengali for the rest of the world) System.
It is my native language. 

I found out there is not enough library to support my language in dotnet eco system.
So, I was thinking of making it happen. I created a nuget package that converts english 
number to bangla number and Georgian Calendar date to Bangla Calendar date.

I went through the official nuget package creation [from here](https://learn.microsoft.com/en-us/nuget/quickstart/create-and-publish-a-package-using-visual-studio?tabs=netcore-cli#create-a-class-library-project)


Nuget Package Link : [Bangla.net](https://www.nuget.org/packages/Bangla.net/#readme-body-tab)
